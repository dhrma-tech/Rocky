| D-023 | 2026-10-08 | I1 egress allowlist is an in-process guard (the SDK's HTTP client plus the connector host's global `fetch`), not an OS firewall or forward proxy. | D-024 | 2026-10-08 | I1 strict review: a proposal is "strict" unless every cited source is a local note or recording (`local-files` connector, type markdown/text/meeting/transcript) with no flags. Computed at read time from citations, so no migration. | Roadmap: "any write proposal shows where the instruction came from and gets stricter review". | D-025 | 2026-10-08 | I1 one-time secrets: verification codes and sign-in/reset links are masked (same length, so offsets stay valid) in `email` and `chat` documents at upsert. The user's own notes are untouched. | Roadmap names email ingestion; chat exports carry OTPs too. |
| D-026 | 2026-10-08 | I1 credential isolation: the connector host is a forked Node process running `apps/daemon/src/connector-host.ts`, started lazily on first use and restarted on the next request after a crash. CLI commands that never sync get no host. | Least change that keeps tokens out of the process that calls models. Same OS user, so it separates code paths, not privileges. |
